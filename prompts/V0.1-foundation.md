# 1. CONTEXTO DEL PROYECTO

Skill-Documentation-AI es un proyecto orientado a automatizar y mejorar la documentación técnica de microservicios Java/Spring Boot mediante inteligencia artificial.

El objetivo general del proyecto es construir una solución capaz de analizar un microservicio Java/Spring Boot, identificar la estructura de su API y utilizar una Skill especializada de documentación junto con un LLM para generar, completar, actualizar y auditar documentación OpenAPI.

El sistema debe ser independiente del proveedor de LLM.

Claude será utilizado durante el desarrollo del proyecto como herramienta de ingeniería, pero el producto final NO debe estar arquitectónicamente acoplado a Claude.

La solución deberá poder evolucionar posteriormente para utilizar diferentes proveedores de LLM, como Claude, Gemini, OpenAI u otros proveedores compatibles, sin modificar la lógica central del sistema.

---

# 2. PROBLEMA QUE RESUELVE

Actualmente la documentación de APIs puede presentar problemas como:

* documentación incompleta;
* endpoints sin documentar;
* parámetros no documentados;
* responses incompletos;
* schemas incompletos;
* documentación desactualizada respecto al código;
* inconsistencias entre microservicios;
* trabajo manual elevado;
* dificultad para mantener documentación empresarial consistente.

El proyecto busca reducir estos problemas mediante automatización, análisis estático y capacidades de LLM controladas mediante una Skill especializada.

---

# 3. OBJETIVO GENERAL DEL PROYECTO

Construir un motor de documentación inteligente capaz de:

1. Analizar microservicios Java/Spring Boot.
2. Identificar sus endpoints y elementos relevantes.
3. Extraer evidencia estructurada del código.
4. Utilizar una Skill especializada en documentación de APIs.
5. Utilizar un LLM intercambiable.
6. Generar documentación OpenAPI.
7. Validar la documentación generada.
8. Auditar la calidad y trazabilidad de la documentación.
9. Detectar posteriormente divergencias entre código y documentación.
10. Integrarse posteriormente con sistemas externos como Confluence.
