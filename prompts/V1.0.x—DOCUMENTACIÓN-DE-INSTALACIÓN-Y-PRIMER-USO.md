# V1.0.x — DOCUMENTACIÓN DE INSTALACIÓN Y PRIMER USO

## Contexto

El proyecto `Skill-Documentation-AI` ya alcanzó V1.0.0 y está publicado en Git con:

- versión: `1.0.0`
- tag: `v1.0.0`
- CLI: `spring-doc`
- paquete Python distribuible: `skill_documentation_ai`
- wheel generado actualmente:
  `skill_documentation_ai-1.0.0-py3-none-any.whl`
- sdist generado actualmente:
  `skill_documentation_ai-1.0.0.tar.gz`

El proyecto ya fue verificado mediante:

- `python -m build`
- instalación desde wheel en un entorno limpio
- ejecución fuera del repositorio
- `spring-doc --version`
- `spring-doc --help`
- ejecución del pipeline básico

Sin embargo, durante una prueba real de instalación se detectó una deficiencia documental:

El README no explica de forma suficientemente clara cómo pasar desde un checkout/clon limpio del repositorio hasta una instalación funcional de `spring-doc`, ni cómo diagnosticar errores comunes relacionados con `dist/`, nombres de wheel, construcción del paquete o diferencia entre el nombre del paquete Python y el comando CLI.

Esta directriz tiene como único objetivo mejorar esa documentación.

8. Problema común: dist/ no existe

Agregar explícitamente troubleshooting para este caso.

Error representativo:

WARNING: Requirement 'dist\....whl' looks like a filename,
but the file does not exist

Explicar:

dist/ contiene artefactos generados durante el build y puede no existir después de clonar el repositorio.

Solución:

python -m build

Después comprobar:

Windows
dir dist
Linux/macOS
ls dist

Y utilizar el nombre real generado.

9. Problema común: nombre incorrecto del wheel

Documentar explícitamente el error:

python -m pip install dist\spring_doc-1.0.0-py3-none-any.whl

si el archivo realmente generado es:

skill_documentation_ai-1.0.0-py3-none-any.whl

Explicar que el comando falla porque pip está intentando abrir un archivo que no existe.

La solución es:

python -m pip install dist\<wheel-generado>.whl

Ejemplo real para V1.0.0:

python -m pip install dist\skill_documentation_ai-1.0.0-py3-none-any.whl

No convertir este nombre en un valor permanente para futuras versiones.

10. Instalación desde wheel

Documentar como camino oficial:

python -m pip install dist/<wheel-generado>.whl

Para Windows mostrar un ejemplo real:

python -m pip install dist\skill_documentation_ai-1.0.0-py3-none-any.whl

Explicar que:

el wheel es el artefacto binario/distribuible;
el nombre depende del paquete y versión;
debe utilizarse el archivo que realmente exista en dist/.

Preferir:

python -m pip install ...

sobre:

pip install ...

para asegurar que pip pertenece al intérprete Python utilizado.
