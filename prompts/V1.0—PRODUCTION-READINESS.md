# V1.0 — PRODUCTION READINESS

## Estado

V0.1 → V0.9 completadas.

Último release:
- tag: v0.9.0
- tests conocidos: 482+
- working tree debe verificarse al iniciar
- V0.9 incluye integración end-to-end de documentación asistida por LLM
- `skills/spring-doc/SKILL.md` funciona en modo independiente y modo opcional de orquestación

V1.0 NO es una nueva fase de funcionalidades de IA.

V1.0 tiene como objetivo convertir el estado funcional alcanzado en V0.9 en una versión estable, instalable, reproducible, documentada y preparada para uso real.

---

# 1. OBJETIVO

V1.0 debe responder afirmativamente a estas preguntas:

1. ¿Puede una persona clonar el repositorio e instalar el proyecto sin conocer su historia?
2. ¿Puede utilizar Analyzer, Generator y Validator de forma predecible?
3. ¿Puede utilizar la CLI sin conocer detalles internos del proyecto?
4. ¿Puede utilizar la API de Python sin depender de módulos internos?
5. ¿Puede utilizar `skills/spring-doc/SKILL.md` desde un agente LLM independientemente del proveedor?
6. ¿El sistema funciona completamente sin un LLM configurado?
7. ¿El enriquecimiento mediante LLM es opcional y seguro?
8. ¿Las credenciales están protegidas?
9. ¿El proyecto puede generar un artefacto instalable reproducible?
10. ¿La documentación describe el comportamiento real del repositorio?
11. ¿Los ejemplos son reproducibles?
12. ¿Los tests protegen las garantías principales del sistema?
13. ¿Existe una definición clara de qué API es pública y qué módulos son internos?

V1.0 debe ser un RELEASE DE ESTABILIZACIÓN, no un nuevo ciclo de funcionalidades.
